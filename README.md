# 🎯 Radar de Prevenção - Loja 482

## 📝 Sobre o Projeto
O **Radar de Prevenção** é um sistema web responsivo desenvolvido para modernizar e automatizar o controle de etiquetas RFID violadas na operação de loja. 

Antes deste sistema, a contagem de peças e o cálculo de prejuízos eram feitos de forma manual através de planilhas no posto de serviço, demandando tempo da liderança para o fechamento dos números do mural da empresa. Este projeto foi criado para solucionar esse gargalo, oferecendo uma ferramenta rápida, segura e automatizada para a equipe de Prevenção de Perdas utilizar diretamente pelo smartphone no salão de vendas.

## ✨ Funcionalidades
- **Autenticação Segura:** Acesso restrito apenas para Fiscais autorizados.
- **Registro em Tempo Real:** Inserção rápida de SKU, Setor, Valor e Descrição da peça.
- **Dashboard Automático:** Cálculo instantâneo do total de peças baixadas e do prejuízo financeiro.
- **Filtros Inteligentes:** Busca de ocorrências por período específico (Data Inicial e Final).
- **Exportação Corporativa:** Geração de relatórios em PDF com hierarquia de assinaturas, gráficos de barras por setor e formatação pronta para auditoria e murais de gestão.

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando tecnologias modernas e que não dependem de servidores complexos:
- **Frontend:** HTML5, CSS3 e JavaScript Vanilla (Design Mobile-First).
- **Backend & Banco de Dados:** Firebase (Firestore para armazenamento em tempo real e Authentication para segurança).
- **Geração de Relatórios:** Bibliotecas `jsPDF` e `jsPDF-AutoTable`.
- **Gráficos Dinâmicos:** Biblioteca `Chart.js`.
- **Hospedagem:** GitHub Pages (CI/CD Automático).

## 📱 Como Usar (Tela Inicial)
O sistema foi desenhado para ser intuitivo. Basta o fiscal acessar o link da aplicação via smartphone, inserir suas credenciais corporativas e começar a registrar as ocorrências. O layout responsivo se adapta perfeitamente a qualquer tela.
